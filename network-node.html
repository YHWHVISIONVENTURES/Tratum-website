Tratum Network Node

Definition

A Tratum Network Node is a secure physical financial endpoint designed to initiate, authenticate, process and synchronize financial activity while connecting activity to institutional financial infrastructure.

Purpose

The Network Node is designed for environments where conventional smartphone-first and continuously connected financial infrastructure can be constrained.

Institutional model

Nodes are intended for deployment through financial institutions and institutional networks rather than as an independent consumer bank.
